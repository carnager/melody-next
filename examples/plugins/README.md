# Example plugins

Templates to start a plugin from; Melody installs none of them. Copy one into
`~/.local/share/melody/plugins/`, enable it under **Settings → Plugins**, and
change it. How plugins work: [docs/plugins.md](../../docs/plugins.md).

| Plugin | What |
| --- | --- |
| [`copy-folder`](copy-folder) | Copies an album's folder, within the music folder, to the clipboard. |
